# 📝 Convertidor de PDF a Word

¡Bienvenido a **Convertidor de PDF a Word**! 🚀 Este script te permite convertir archivos PDF a documentos de Word (DOCX) de manera fácil y rápida.

## 📌 Características
✔️ Convierte archivos PDF a Word con un solo comando.  
✔️ Manejo de errores: verifica la existencia del archivo antes de la conversión.  
✔️ Posibilidad de especificar el nombre de salida o usar el mismo nombre que el PDF.  

## 🔧 Instalación
Antes de ejecutar el script, asegúrate de tener instaladas las dependencias necesarias.

pip install pdf2docx
